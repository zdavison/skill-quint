# skill-quint

Claude Code skill for working with [Quint](https://quint.sh), the formal specification language. Originally derived from [informalsystems/quint-llm-kit](https://github.com/informalsystems/quint-llm-kit).

## Install

Via the [zdavison marketplace](https://github.com/zdavison/claude-skills):

```
/plugin marketplace add zdavison/claude-skills
/plugin install quint@zdavison
```

## What's inside

A single `quint` skill that loads when you work on `.qnt` files or anything formal-specification-adjacent. Reference files cover language constraints, implementation patterns, iteration on errors, planning, verification, test debugging, and Choreo test patterns.
